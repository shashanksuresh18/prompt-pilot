# PromptPilot – Smart Prompt Helper for AI

PromptPilot is a Chrome extension that turns rough, messy prompts into **structured, high-quality super-prompts** directly inside **ChatGPT, Claude, and Gemini**.

Stop wasting time thinking about how to phrase things. PromptPilot **detects your intent** (coding, data, travel, resume, etc.) and builds a tailored prompt with professional structure: Role, Goal, Context, Constraints, and Output Format.

---

## ✨ NEW in v0.2.0
- **Multi-Platform Support**: Works seamlessly on ChatGPT, Claude, and Gemini.
- **Preview Modal**: Review and edit the enhanced prompt before it replaces your input.
- **Customizable Tone**: Choose between Professional, Casual, Concise, or Detailed tones in the setings.
- **Category Toggles**: Enable/Disable specific prompt templates.

## 🚀 Features

### 🧠 Intent-aware enhancement
Automatically detects what you’re trying to do:
- `coding` – debugging, scripts, APIs, Python/JS/SQL…
- `data` – Excel / Sheets / CSV / Tableau / SQL
- `app_build` – “build a web app / SaaS / product”
- `rewrite` – summarise, fix grammar, simplify text
- `content_creation` – blogs, LinkedIn posts, tweets
- `travel` – trip planning & logistics
- `resume`, `email`, `explanation`, `brainstorm`, and more.

### 🧩 Structured super-prompts
Every enhanced prompt follows a consistent, high-leverage pattern.

### 🛡️ Privacy First
- All logic runs **locally** in your browser.
- **No data** is sent to external servers.
- No analytics or tracking.

## 🛠️ Installation (Local/Dev)
1. Go to `chrome://extensions`.
2. Enable **Developer Mode**.
3. Click **Load Unpacked** and select this folder.
